# -Faster-R-CNN-
這個專案主要是用 AI 深度學習技術，幫工廠跟工地做一套「安全裝備自動檢查系統」。選用了很有名的兩階段物件偵測演算法 Faster R-CNN，搭配 ResNet-50 和 FPN 網路來抓取影像特徵。用 Google Colab 雲端環境跟 PyTorch 框架，針對 6 種常見的工地目標進行完整的訓練與測試，用自動化辨識來代替人工檢查，讓工安管理更有效率。
本專案之模型訓練資料是從 Roboflow 平臺篩選出的真實工地與工廠影像，共計 856 張，透過深度學習物件偵測演算法，實現對現場人員與防護裝備的自動化識別。

本系統於 Google Colab 環境下開發，並掛載 Google Drive 讀取資料與儲存權重。程式架構區分為以下核心模組：
讀取資料與座標轉換：寫了 ConstructionSiteDataset 來讀照片。因為原本抓下來的資料是 YOLO 格式（歸一化後的中心點和長寬），但 Faster R-CNN 需要的是絕對座標（左上角和右下角的像素位置）。所以程式在讀照片時，會自動抓出照片的真實寬高，即時把它們乘開算成絕對座標，並把畫錯的無效框過濾掉。

設定模型與優化器：載入官方的模型後，把最後的分類器改成專案的 7 分類。優化器選擇 AdamW，學習率跟權重衰減都設定為 0.0005。

訓練模型：總共跑 50 個 Epoch，每次抓 16 張照片（Batch Size = 16）給模型。模型在訓練時會計算總損失（Total Loss）、分類損失、邊框損失，然後透過反向傳播更新模型權重。

1:1 特徵配對評估：測試時把模型切換到測試模式（eval()）。用交併比（IoU）來比對，模型的預測框跟真實的標註框疊合面積必須大於等於 50%（IoU >= 0.50），才算是有抓對地方。

7x7 混淆矩陣：為了看清模型的缺點，把「背景」算進去。如果模型把路燈或強光誤看成是背心（虛警），就會被歸類在混淆矩陣的背景列；如果是真實存在的安全帽模型卻沒看到（漏檢），就會被歸類在背景行。最後做出一個包含 6 類目標 + 1 類背景的 7x7 混淆矩陣，並且畫出 Precision、Recall、PR、F1 曲線，以及 Loss 下降圖。
